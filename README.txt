# Machine Learning Based Heart Disease Prediction

The aim of this project is to predict heart disease based on clinical and lifestyle data using machine learning techniques.

This includes:

- Dataset for heart disease

- ML model (trained) (`.pkl`)

- Jupyter Notebook

- Publication

## Techniques

- Logistic Regression

- Decision Tree

- Random Forest

- SVM

- KNN

Out of all the types used, Decision Tree and Random Forest performed the best.

## Tools

Python, Scikit-learn, Pandas, Numpy, Matplotlib, Jupyter Notebook
